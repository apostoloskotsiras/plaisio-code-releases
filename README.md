# Plaisio Code

Builds of the Plaisio Code app, for installing and updating it. No source code here.

## Android

On the phone, open [app-release.apk](https://github.com/apostoloskotsiras/plaisio-code-releases/releases/latest/download/app-release.apk) and install it; allow installs from your browser if Android asks. After that, the app offers each update itself when you open it.

## iPhone (iOS 26 or later)

Add this source in SideStore, AltStore or Feather, then install Plaisio Code from it:

```
https://raw.githubusercontent.com/apostoloskotsiras/plaisio-code-releases/main/source.json
```

When an update is out, the app says so; update it from the same app you installed it with.
