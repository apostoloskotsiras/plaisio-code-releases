<h1 align="center">Plaisio Code</h1>
<p align="center">Builds of the Plaisio Code app, for installing and updating it. No source code here.</p>

## iPhone (iOS 26 or later)

On the iPhone, tap the app you sideload with. It opens and adds the Plaisio Code source; then tap **Get** on Plaisio Code there. Updates come through the same app, and Plaisio Code says when one is out.
